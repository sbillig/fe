Added the `#[abi]` struct attribute. An `#[abi]` struct gets `AbiSize`, `AbiSpan<Sol>`, `Encode<Sol>` and `Decode<Sol>` implementations that encode it like the Solidity tuple of its fields, so Solidity structs such as `PoolKey` can be used in `msg` fields and return types, in arrays and inside other `#[abi]` structs without hand-written codecs. When all their fields implement `SolCompat`, `#[abi]` structs do too, with the Solidity tuple type of their fields, e.g. `(uint8,address,uint256)`, so they can be used as `#[event]` and `#[error]` fields, including in arrays such as Seaport's `OrderFulfilled(bytes32,address,address,address,(uint8,address,uint256,uint256)[],(uint8,address,uint256,uint256,address)[])`.
