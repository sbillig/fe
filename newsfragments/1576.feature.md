Support boolean const `where` predicates on items, such as `fn operation() where allowed(3) {}`, `const fn bounded<const N: usize>() where N > 0` and `struct Bounded<const N: usize> where N > 0`. Conditions without generic parameters are evaluated and reported where they are declared, even if the item is unused. Conditions on the generic parameters of functions, structs, enums and inherent methods are checked wherever such an item or type is written or an expression instantiates it, and a generic caller, including an anonymous constant in its signature or body, satisfies one only by stating the same condition. Inside an `impl`, the conditions of the types in its self type hold without restating them (a trait impl's trait arguments supply none), and a generic type alias assumes those of its aliased type. A condition that needs several lines can be written as a block, `where { ... }`. Const predicates in traits, generic trait impls and on generic `impl` blocks themselves are rejected for now.
