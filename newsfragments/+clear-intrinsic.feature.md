Storage elements can be cleared like Solidity's `delete`. `core::ops::clear_storage(mut collection, key)` zeroes the element at `key` of a collection whose elements live in storage or transient storage, where a slot no one wrote reads as zero, so zero is a value of every type there; a collection keeping its elements in memory is rejected by its `where C::SPACE.starts_zeroed()` requirement. `StorageMap::remove(key)`, `SolArray::clear()`, `TSlot::clear()` and `SolEnumerableSet::clear()` use it, and `SolArray::pop` zeroes every slot of a struct element and no longer needs `T: Default`. Underneath, `unsafe fn core::intrinsic::clear<T>(_ place: mut T)` zeroes any place's representation: its bytes in memory, its words in storage or transient storage, and only its own bits of a packed slot.
