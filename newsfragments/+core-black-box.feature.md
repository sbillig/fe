Added `core::hint::black_box`, which returns a scalar unchanged while hiding it from the optimizer. The computation that produces the argument is kept even when the result is unused, and the call stays ordered with respect to other effects, so gas benchmarks can pass their inputs and results through it between two `evm.gas()` reads. It emits no EVM instructions, apart from a `POP` when the result is unused. Only EVM targets support it.
