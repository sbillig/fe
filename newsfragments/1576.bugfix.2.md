Report errors in anonymous constants in types and in the generic arguments of types, traits and functions, including in a type parameter's default. `[u8; { n }]` with a runtime `n` panicked, and an undefined name there, or in a default argument that an alias drops, such as `struct S<T = Drop<{ nope }>>` with `type Drop<const N: usize> = u8`, compiled without an error.
