A `mut` contract field can name its root slot with `#[slot(e)]`, where `e` is any constant `u256` expression, including `const fn` calls and `core::keccak`. ERC-7201 namespaced storage, for example, is `#[slot(keccak(keccak("example.main") - 1) & !(0xff as u256))]`. A placed field takes the slots from `e` on, and the fields without `#[slot]` are numbered as before but skip the slots placed fields of their address space take. Placed fields whose slots overlap in one address space are rejected; storage and transient storage are separate spaces, so the same slot number can be used in each. `#[slot]` on an immutable field, which lives in code, or on a struct field is an error. The parser now accepts an expression as an attribute argument.
