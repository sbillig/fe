Parse comparisons separated by commas in call arguments and tuples, such as `f(a < b, c > d)` and `(a < b, c > 0)`, as comparisons. They were read as generic arguments and failed to parse. A comparison whose `>` is followed by a token that can continue an expression, as in `f(a < b, c > (d))`, is still read as generic arguments; parenthesize it, as in `(c > (d))`.
