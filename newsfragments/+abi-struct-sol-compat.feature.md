`#[abi]` structs now also implement `SolCompat` with the Solidity tuple type of their fields, e.g. `(uint8,address,uint256)`, so they can be used as `#[event]` and `#[error]` fields, including in arrays such as Seaport's `OrderFulfilled(bytes32,address,address,address,(uint8,address,uint256,uint256)[],(uint8,address,uint256,uint256,address)[])`. Previously such events failed to compile with an internal CTFE error about `TOPIC0`.
