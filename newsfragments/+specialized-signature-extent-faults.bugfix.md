A computed array length that faults for a concrete instantiation is now reported as an invalid concrete type where it is used, with the faulting expression, when it reaches the instance through a called function's parameter or return type or through a field of a parameter. Previously such uses (for example `bad<0>()` returning `[u8; { N - 1 }]`, or an unused parameter of type `Words<0>` whose field length faults) crashed the compiler or reported an internal error.
